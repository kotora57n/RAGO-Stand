# RAGO STAND — Webサイト README

絵本＋屋台「RAGO STAND」のスマホ向け縦スライドWebサイトです。

---

## 🗂 ファイル構成

```
RAGOStand/
├── index.html      サイト本体（スライドはJSで自動生成）
├── style.css       全スタイル
├── main.js         スライド生成・切り替えロジック
├── data.js         ★ テキスト・画像・動画IDの差し替えはここだけ編集
├── assets/
│   ├── logo.png        ロゴ画像（背景透過PNG）
│   ├── chara1.webp 〜 chara5.webp   キャラクター画像
│   └── images/         既存画像フォルダ
└── README.md       このファイル
```

---

## ✏️ コンテンツの差し替え方法

### テキストを変える

`data.js` を開き、各項目を書き換えてください。

```js
// 例：キャラクター1の名前とキャッチコピーを変える
{
  name: "",              // 空文字なら名前非表示
  catch: "どこへでも行くよ、\nきみのそばに。",
  text:  "紹介文...",
  from:  "#f28c28",      // グラデーション上端の色
  to:    "#0d0d0d",      // グラデーション下端の色
  image: "assets/chara1.webp"
}
```

### 動画IDを設定する

`data.js` の末尾にある `youtubeId` にYouTubeの動画IDを入力します。

```js
youtubeId: "dQw4w9WgXcQ"   // YouTube URLの ?v= 以降の部分
```

> **注意**: 動画は「埋め込み許可」がオンになっている必要があります。  
> YouTube Studio → 動画設定 → 「埋め込みを許可」にチェック。

### 表紙の背景画像を設定する

```js
cover: {
  title: "絵本のタイトル",
  bgImage: "assets/cover.jpg"   // 画像パスを入力（空文字なら白背景）
}
```

## 🖼 画像の仕様

| ファイル名 | 推奨サイズ | 形式 | 備考 |
|-----------|-----------|------|------|
| `assets/logo.png` | 幅800px | PNG（背景透過） | 提供済み |
| 表紙の絵（任意） | 1080×2400px | JPG / WebP | 縦長・高解像度 |
| `assets/chara1.webp` 〜 `chara5.webp` | 1200×1600px（3:4比） | WebP（背景透過） | 各500KB以内。5体すべて足元の位置・大きさをそろえる |

> **キャラクター画像のポイント**: 足元を画像の下端にそろえてください。  
> サイトでは画面の下端に吸い付くように配置されます。

## 🌈 グラデーションの色を変える

`data.js` の各キャラクターの `from` / `to` を変更します。

```js
from: "#f28c28",   // ← 上端の色（例: オレンジ）
to:   "#0d0d0d",   // ← 下端の色（通常は黒のまま）
```

**使用可能な色（デザインルール）**: 白 / 黒 / オレンジ / ブルー のみ。

## 🚀 ローカルで確認する方法

ファイルをダブルクリックで開くと `file://` プロトコルになり、一部機能が動作しません。  
ローカルサーバーを使用してください。

### VS Code の Live Server を使う場合
1. VS Code で `RAGOStand` フォルダを開く
2. `index.html` を右クリック → 「Open with Live Server」

### npx を使う場合（Node.js が必要）
```bash
npx serve .
```
ブラウザで `http://localhost:3000` を開いてください。
